# GOLDEN RULES
RULE 1: UX before UI.
RULE 2: Design before code.
RULE 3: Reuse before duplicate.
RULE 4: Mobile is not an afterthought.
RULE 5: Every interaction needs feedback.
RULE 6: Every component needs states.
RULE 7: Every decision needs a reason.
RULE 8: Don't add complexity without value.
RULE 9: Don't optimize aesthetics over usability.
RULE 10: Don't stop at "it works".
RULE 11: Inspect rendered result, not just code.
RULE 12: Fix problems instead of explaining them.
RULE 13: Build systems, not isolated screens.
RULE 14: Design for real users, not screenshots.
RULE 15: Production-ready = UX + UI + Code + Accessibility + Responsive + Edge Cases.
